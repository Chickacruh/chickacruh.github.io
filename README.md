# Local portfolio

Open http://localhost:4173 while the local server is running.

Double-click **Start Portfolio.cmd** to start the server again and open your browser.

This folder contains a local copy of the published homepage, all four project pages, images, fonts, and browser scripts. Edit the HTML files to change the published content. The original Figma authoring project is not included.

Localhost opens on this computer only. The resume is saved locally as assets/resume.pdf. Navigation stays within the local portfolio. The original website remains available at its existing address.

The publisher's RSS feed returned 404 on the original site; its broken feed link was removed locally.
